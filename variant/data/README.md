# Information on Data Collection

Data collection and organization are required before processing fine-mapping result data.

The folders BBJ, CAUSALdb, FinnGen, and UKBB represent the overview information of traits from each fine-mapping result data source.

[source.xlsx](source.xlsx): Source information for organizing fine-mapping result data.

[trait_info.txt](trait_info.txt): Unfiltered results of the organized fine-mapping data.

[trait_info_have.txt](trait_info_have.txt): Filtered results of the organized fine-mapping data.
